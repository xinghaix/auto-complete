## Origin (summary)

Core completion behavior is drawn from open-source **[kilocode](https://github.com/Kilo-Org/kilocode)** (with classic references in [kilocode-legacy](https://github.com/Kilo-Org/kilocode-legacy)).  
After **v7**, the full product became heavier; this repo **extracts code completion** into a focused project.

- **Now:** JetBrains IDE plugin only  
- **Planned:** VS Code extension  

See [SOURCES.md](SOURCES.md) for mapping notes.
